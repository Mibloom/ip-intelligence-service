# Security Policy

## Reporting a vulnerability

Do not include credentials, production IP addresses, request logs, or user data
in a public issue.

Use GitHub's private vulnerability reporting or open a draft security advisory
in the repository's **Security** tab. Include the affected version, impact,
reproduction steps, and a minimal proof of concept. Please allow the maintainers
time to investigate before public disclosure.

## Supported versions

Security fixes are applied to the latest revision of the default branch. No
older release line is currently maintained.
